# 2025 Movies Hub 

Welcome to my portfolio and movide site for 2025!
This project showcases trending movies, box office results, and upcoming releases, all styled for modern, easy-to-read experience. 


## Features

- **Trending Movies:** See what's hot right now, pwoered by TMDb API. 
- **2025 Biggest Box Office Hits:**  
  - Left column: Movie title, release date, genre, distributor  
  - Center column: Domestic, foreign, and worldwide box office totals  
  - Right column: Movie poster
- **Upcoming Releases:** Stay updated on future movie premieres.
- **Contact Form:** Reach out for feedback or questions.

## Technologies Used

- **HTML5** & **CSS3** (Flexbox, gradients, responsive design)
- **JavaScript** (API integration)
- **TMDb API** for live movie data

## How to Run

1. Clone or download this repository.
2. Place your movie poster images in the `/images` folder.
3. Open `index.html` in your browser.
4. Make sure your TMDb API key is set in `script.js` for trending/upcoming movies.

## File Structure

- `index.html` — Main page with trending and box office movies
- `styles.css` — Custom styles for layout and colors
- `script.js` — Fetches movie data from TMDb API
- `/images` — Movie poster images

## Customization

- Add or update movies in the `<ul class="movie-list">` section of `index.html`.
- Change colors and layout in `styles.css` as you like.
- Update API calls in `script.js` for more or fewer movies.
